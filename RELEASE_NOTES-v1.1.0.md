# DimLite 1.1.0

## Русский

Обновление для первого публичного релиза.

- Добавлена кнопка «Проверить обновления» в настройках.
- Добавлена опциональная автоматическая проверка и установка обновлений.
- Установщик скачивается по HTTPS и проверяется по SHA-256 до запуска.
- Добавлен полноценный Windows Setup.exe с удалением через список установленных приложений.
- Галочка в настройках перерисована сглаженно и аккуратно масштабируется на DPI.

Файлы релиза:

- `DimLite-1.1.0-Setup.exe` — установщик.
- `DimLite-1.1.0-win-x64.zip` — portable-версия.
- `.sha256` — контрольные суммы.

## English

Update to the first public release.

- Added a “Check for updates” button to Settings.
- Added an opt-in automatic update check and installation flow.
- The installer is downloaded over HTTPS and verified with SHA-256 before launch.
- Added a full Windows Setup.exe with a normal uninstall entry.
- Improved the checkbox rendering with anti-aliased, DPI-aware checkmarks.

Release files:

- `DimLite-1.1.0-Setup.exe` — installer.
- `DimLite-1.1.0-win-x64.zip` — portable build.
- `.sha256` — checksums.

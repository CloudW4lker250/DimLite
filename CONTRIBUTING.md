# Contributing

Issues and pull requests are welcome.

## Before opening a pull request

1. Build the application with `source\build.ps1` on Windows 10/11 x64.
2. Check that the application exits cleanly and restores the desktop color transform.
3. Keep the application native and event-driven. Do not add network access, telemetry, Electron or a permanent polling loop.
4. Do not commit user settings, profile files, compiler output, crash dumps or personal paths.
5. Describe any Windows version, DPI, monitor or full-screen limitation in the pull request.

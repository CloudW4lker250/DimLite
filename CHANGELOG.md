# Changelog

## 1.0.0 — 2026-11-13

- First public GitHub release.
- Added compact Windows-style brightness OSD.
- Added direct click-to-position and dragging on all brightness sliders.
- Added smooth transitions, application profiles and brightness lock.
- Added settings page with themes, startup, icon and version controls.
- Added recovery helper for unexpected exits.
- Kept the implementation native and event-driven with no network access or telemetry.
